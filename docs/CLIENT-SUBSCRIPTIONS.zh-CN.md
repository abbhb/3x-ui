# 客户端外部订阅

客户端的“链接”页展示当前套餐授予的来源和节点，以及关联账号启用的私有来源。
管理员可在这里管理该客户的私有来源。用户门户读取同一份授权和私有来源，同时展示客户端直配记录的备注。
套餐继承项只读。保存客户端直配链接不会把继承节点复制成永久授权。

原生客户端远程 URL 支持分享链接列表、Base64 列表和 Clash/Mihomo YAML。来源库的 URL 刷新和手动导入也支持这三种输入。
YAML 仅导入节点。来源库保留加密快照，原生直配 URL 延续原有的按需抓取和缓存。
受支持的分享链接连同节点快照加密保存，供 URI 和 Xray JSON 复用。历史 YAML 快照在读取时判断格式：
基础 HY2、Trojan 和 Shadowsocks 可转成分享链接；含未映射选项的节点继续供应 Mihomo。
客户端和门户逐节点显示可用格式。原订阅地址、套餐选择和已有节点 ID 保持有效。

在隔离环境中验收：一个套餐从公共来源勾选部分节点；同一客户自行添加私有节点，管理员再添加一条直配。
比对客户端“链接”、门户和实际订阅。切换到另一账号应看不到前者的私有项。
换套餐、禁用私有来源后重新订阅，对应授权应随之消失。
